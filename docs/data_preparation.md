# Data Preparation

## Source Data

The project uses four PostgreSQL tables:

- facebook_ads_basic_daily
- facebook_campaign
- facebook_adset
- google_ads_basic_daily

## Preparation Workflow

1. Explore source tables
2. Join Facebook lookup tables
3. Standardize field names
4. Add advertising source
5. Decode UTM campaigns
6. Handle missing values
7. Aggregate marketing metrics
8. Export dataset to CSV
9. Import into Tableau Public

## Technologies

- PostgreSQL
- SQL
- DBeaver
